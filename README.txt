MAC修改助手 1.2.0

底部导航：修改 / 地址库 / 模块 / 记录。
1.2.0 更新：统一应用名称，改用带线条图标、选中胶囊和点击反馈的悬浮底栏。

首次使用
1. 在 Root 管理器允许 cn.macmanual，在“模块”中点击“申请 / 检查 Root”。
2. Wi-Fi 需要启用本 LSPosed 模块，作用域选“系统框架 / android”，停用旧 MACsposed Fork，并重启一次。
3. 在“修改”中刷新接口、选择网卡、输入 MAC，点击“立即修改”并确认。
4. Wi-Fi 会自动保存固定配置，再修改接口并回读。无需先手动保存固定配置。
5. USB 网卡必须先被系统识别为网络接口，再选择对应接口修改。USB 修改不依赖 LSPosed。

地址库
点击“保存到地址库”填写名称，或在“地址库”添加地址；以后点击“应用”并确认即可。
支持编辑、删除。多个同类接口时会要求选择接口。升级保留地址库，卸载会清除。

关闭与恢复
“模块”可以关闭 Wi-Fi 固定模式；下次连接交还系统管理，当前地址不会立即恢复。
“恢复修改前地址”只适用于本应用修改过的同一次开机、同一个接口实例；恢复值不保证是出厂地址。
恢复 Wi-Fi 时也会更新固定配置。若需要系统管理，请再主动关闭固定模式。
固定设置存在 Settings.Global；卸载应用前建议关闭固定模式。停用 LSPosed 模块并重启后 Hook 不再运行。

限制
改址会短暂断网，驱动是否支持以实际返回和回读为准；失败时会尝试恢复旧配置、地址与链路状态。
不修改固件、EEPROM、热点或蓝牙。USB 拔插后可能恢复默认地址，不提供开机 / 插入自动应用。
完全未枚举的 USB 设备无法通过 MAC 改址解决识别问题。

验证
1.1.0 已验证 Root Android 15 设备的 Wi-Fi 自动固定、实际改址和恢复，以及导航、地址库持久化与参数保护。
1.2.0 更新名称与导航，已验证构建、签名、27 项脚本测试、218 项 Java 断言；发布时手机未连接，未重复实机界面测试。
USB 硬件改址尚未完成实机验证。
